# ADR-20260929：产品级重构——景深·沉浸光感·玻璃语言 + 应用外壳与四入口信息架构

- 状态：待确认（Phase 2.5 CHECKPOINT）
- 日期：2026-09-29
- 触发：用户要求「整体 UI / 功能 / 布局 / 界面大改」：右上角用户信息保持；移动端底部胶囊导航（概览/地图/日历/我的）；左上角侧边栏入口；磨砂玻璃卡片 + 悬浮胶囊；模糊景深；自定义首页背景；美学=景深+沉浸光感+玻璃；登录改为灵动起始动画 + 落地页。
- 范围（阶段 1 建议）：设计系统 v3 + 应用外壳（侧边栏/底栏）+ 四入口页面（概览/地图 v1/日历/我的）+ 背景自定义 + 落地页与登录重构 + 概览/详情玻璃化
- 不包含：腾讯地图 SDK 真接入（需备案域名 + key）、图片上传到 COS、深色模式、后端改动（本轮零接口变更）

## 1. 需求拆解与现状差距

| 用户诉求 | 现状 | 差距 |
|---|---|---|
| 移动端底部胶囊导航（概览/地图/日历/我的） | 无底部导航；仅 FAB | 需新建导航 + 两个新页面（地图/日历）+「我的」页 |
| 左上角侧边栏入口 | 顶栏只有品牌；无侧边栏 | 需新建侧边抽屉 + 功能清单 |
| 磨砂玻璃卡片 / 悬浮胶囊 / 强阴影 | 实心卡片 + 轻阴影 | 需玻璃配方与悬浮层级 |
| 模糊景深 / 沉浸光感 | 纯色薄荷底 | 需背景舞台（自定义背景 + 动态光斑 + 遮罩） |
| 自定义首页背景 | 无 | 需背景系统（预设/URL/本地上传）+ 持久化 |
| 登录 = 灵动动画 + 落地页 | 两栏静态表单（AuthShell） | 需落地页 + 动画 + 玻璃登录面板 |
| 功能大改 | 仅行程列表/详情 | 新增我的（资料/统计/外观/关于）、日历（月视图）、地图（v1 清单；SDK 待 key） |

**关键判断**：这不是换肤，而是「外壳 + 信息架构 + 三个新页面 + 背景系统」的组合改动。视觉语言（上一轮的青野·自然）作为**品牌色保留**，在其上叠加玻璃/景深/光感层次，避免全盘推翻已有令牌与对比度成果。

## 2. 设计语言 v3：景深 · 沉浸光感 · 玻璃

### 2.1 层次模型（自下而上）

```
L0 背景基座     用户自定义（预设渐变 / 图片 URL / 本地上传）+ 亮度遮罩(scrim)
L1 光晕层       2-3 个缓慢漂移的极光光斑（GPU 动画；reduced-motion 关闭）
L2 内容层       半透明玻璃卡（无模糊或桌面端轻模糊）——承载行程/日历/列表
L3 悬浮层       真·磨砂玻璃（backdrop-filter）：顶栏、底部胶囊导航、FAB、抽屉
L4 覆盖层       弹窗/表单抽屉（玻璃 + 强阴影）
```

### 2.2 玻璃配方（令牌）

```css
--wy-glass-float-bg: rgba(255,255,255,0.62);   /* 悬浮层：带 blur */
--wy-glass-panel-bg: rgba(255,255,255,0.78);   /* 内容面板：承载正文（配合遮罩保证对比度） */
--wy-glass-panel-strong: rgba(255,255,255,0.88); /* 密集正文（表单/详情） */
--wy-glass-stroke: rgba(255,255,255,0.55);     /* 1px 高光描边 */
--wy-glass-blur: 18px;                          /* backdrop-filter: blur() saturate(140%) */
--wy-glass-shadow: 0 12px 32px rgba(15,46,36,0.14), 0 2px 8px rgba(15,46,36,0.08);
--wy-float-shadow: 0 16px 40px rgba(15,46,36,0.20); /* 胶囊悬浮 */
```

### 2.3 纪律（防"廉价玻璃"与性能塌方）

| 规则 | 说明 |
|---|---|
| **模糊只属于悬浮层** | `backdrop-filter` 仅用于顶栏/底栏/FAB/抽屉/弹窗（同屏 ≤4 层）；内容卡用「半透明白 + 阴影」模拟玻璃感。桌面端（hover 设备）可对卡片加 `blur(8px)` 增强 |
| 不叠加模糊 | 禁止"玻璃里套玻璃"；抽屉内的卡片不再模糊 |
| 对比度保障 | 背景舞台强制叠加 scrim（白 55%→35% 垂直渐变），玻璃面板不透明度 ≥0.78；正文对比度按**复合色**计算（见 §7 V2） |
| 动效 | 光斑漂移 18-24s 周期、`transform/opacity` only；`prefers-reduced-motion` 全关；开关可由用户关闭光斑 |
| 回退 | `@supports not (backdrop-filter: blur(1px))` → 悬浮层改为 0.92 不透明实底 |


- 侧边抽屉在桌面/移动端均可用（`el-drawer` 玻璃化，宽 280/86%）。
- 侧边栏「外观设置」直接打开背景设置面板（不必进"我的"）；「关于」展示版本信息。
- 底部导航仅在移动端显示（`<768px`）；桌面用顶栏 + 侧边栏。

## 4. 页面设计要点

### 4.1 落地页（`/`）
- 背景舞台 + 品牌动画：SVG 路线**描边绘制**（stroke-dashoffset 动画）→ 落点 pin 弹出 → 标题上浮；总时长 ≤1.6s，reduced-motion 直接呈现终态。
- 文案：主标题「把想去的地方，变成下一段旅途」；副题一行；CTA 主按钮「开始规划」→ `/register`，次按钮「已有账号」→ `/login`。
- 三张玻璃特性卡：行程规划 / 日历与地图 / 随心外观（各含一句说明 + 图标）。
- 底部：版本号与一句 slogan。

### 4.2 登录 / 注册
- 去掉两栏叙事，统一为「同一背景舞台 + 居中玻璃面板」；面板含品牌小标 + 标题 + 表单。
- 表单语义**不可破坏**（原生提交 + name/autocomplete + 整页跳转），否则密码管理器回归失败（见既有 ADR）。

### 4.3 概览（`/trips`）
- 保留票根→渐变卡→玻璃卡演进：`glass-panel` 半透明卡 + 渐变头 + 状态胶囊 + 倒计时胶囊；错峰入场不变。

### 4.4 日历（`/calendar`，新增）
- 月视图：7 列网格；日期格显示行程色点（按行程渐变取色，最多 3 点 + 溢出数字）；今天高亮；上/下月切换 + 「回到今天」。
- 数据：`/trips` + 逐行程 `/days`（N+1，行程数小可接受；后端聚合端点列 backlog）。
- 交互：点击有行程的日期 → 弹出当日行程/日程胶囊列表（玻璃 sheet）→ 点击进入行程详情。
- 状态管理：无日期行程在网格下方"未定日期"区展示。

### 4.5 地图（`/map`，新增 v1）
- 顶部说明卡：「完整地图即将上线（待备案域名 + 腾讯地图 Key）」，避免误导。
- 主体：有坐标的地点按行程分组的清单（名称/地址/时间/分类），操作：在腾讯地图打开（既有 URI）/ 复制坐标；无坐标地点提示"补充经纬度后出现在这里"。
- 数据结构预留 SDK 接入：`{ trip, places: [{id, name, lat, lng, ...}] }`。

### 4.6 我的（`/me`，新增）
- 资料卡：头像字、昵称/邮箱、注册时间（`/auth/me`）。
- 统计卡：行程数 / 已安排天数 / 地点数（来自列表计数字段，零额外请求）。
- 外观设置：背景选择器（预设 6 组 / 图片 URL / 本地上传）、光斑动画开关。
- 关于：版本（`VITE_APP_VERSION`）、仓库链接、退出登录。

## 5. 背景系统（自定义首页背景）

| 能力 | 实现 | 边界 |
|---|---|---|
| 预设 | 6 组极光渐变（与目的地渐变色板同源） | 纯 CSS，零成本 |
| 图片 URL | `background-image: url(...)` + 加载失败回退预设 | 外链可能失效/防盗链 |
| 本地上传 | canvas 压缩（长边 ≤1920、JPEG q0.82）→ dataURL → `localStorage`（键 `wy.background`），**上限 1.2MB**，超限提示换小图 | localStorage 5MB 上限；未来接入 COS 后改为 URL |
| 可读性 | 背景舞台固定叠加 scrim（白 55%→35%）+ 光斑模式自动降透明度 | 任意用户图都不得低于对比度下限（§7 V2 量化） |
| 持久化 | Pinia `stores/appearance.ts` + localStorage；启动时应用为 CSS 变量 `--wy-user-bg` | 清站点数据会丢失（可接受） |

## 8. 风险与反例

| 风险 | 对策 |
|---|---|
| 玻璃层过多导致移动端掉帧 | 模糊仅悬浮层；卡片用半透明+阴影；桌面端才允许卡片轻模糊 |
| 自定义背景压垮文字可读性 | 强制 scrim + 面板不透明度下限 + G2 复合对比度脚本 |
| localStorage 容量（背景 dataURL） | 压缩 + 1.2MB 上限 + 明确报错；未来 COS |
| N+1 请求（日历/地图需按行程取天/地点） | 行程数量级小可接受；后端聚合端点列 backlog（ADR 记录边界） |
| 落地页动画喧宾夺主 | ≤1.6s、只播一次、reduced-motion 直落终态 |
| 地图页"看起来像坏掉了"（无真地图） | 明确的上线说明卡 + 可用替代（清单/跳转），避免虚假承诺 |
| 详情页在阶段 1 只做玻璃化、不深改 | 继承令牌自动一致；深度打磨列阶段 2，避免单轮 diff 过大 |

## 9. 范围与分阶段建议

- **阶段 1（本 ADR 覆盖，推荐一次做完）**：设计系统 v3 + 外壳 + 四入口页面（地图为 v1 清单版）+ 背景自定义 + 落地页/登录重构 + 概览/详情玻璃化。理由：底部导航四入口必须"处处可去"，否则导航结构不成立。
- **阶段 2（下一轮）**：腾讯地图 SDK 真接入（备案 + key 就绪后）、详情页深度打磨（时间轴动效/拖拽排序）、日历交互增强（周视图、拖拽改期）、深色模式。

## 10. 决策记录（用户已确认）

1. **范围**：阶段 1 一次做完（外壳 + 四入口 + 背景自定义 + 落地页 + 概览/详情玻璃化）。
2. **品牌色**：改用**翡翠宝石色系**——主色深翡翠 `#047857`（白字达标），亮翡翠 `#10B981` 用于渐变/光晕，青玉 `#0F766E` 作辅助文字色；目的地渐变板改为宝石家族（翡翠/青玉/蓝宝石/琥珀/橄榄石/紫水晶）；悬浮元素增加"宝石高光"（内侧 1px 白边）与光晕投影。**注意：色值需按 §7 G2 重新审计**（深翡翠 `#047857` 白字 5.48:1、青玉文字在青玉弱底达标值待验证）。
3. **地图**：v1 清单版（坐标清单 + 跳转腾讯地图 + 待接入说明），SDK 待备案与 key。
4. **背景**：完整版（预设 6 组 + 图片 URL + 本地上传压缩 1.2MB 上限）。

## 11. 最终结果（Phase 5）

- 实际变更：
  - **设计系统 v3**：`tokens.css` 全量重写（翡翠宝石主色 + 玻璃配方 + 宝石家族目的地渐变 + 极光光斑 + 6 组预设背景 + 可读性遮罩）；`base.css` 新增 `.glass-float/.glass-panel/.glass-panel-strong`（模糊仅悬浮层、桌面端卡片轻模糊、`@supports` 回退）与极光/描边动画；`element.css` 将弹窗/抽屉/消息框/浮层全面玻璃化。
  - **应用外壳**：`App.vue` 统一渲染 `BackgroundStage`（L0 背景 + 遮罩 + L1 光斑）、`AppBar`（左上 ☰ / 返回，右上用户信息保持原样）、`SideNav`（280px 玻璃抽屉：四入口 + 外观设置）、`BottomNav`（移动端玻璃胶囊：概览/地图/日历/我的）、`AppearanceSheet`（全局单实例）。
  - **新页面**：`LandingView`（落地页：路径描边动画 + 落点 + 特性玻璃卡 + 双 CTA）、`CalendarView`（月视图 + 宝石色点 + 当日弹出面板 + 未定日期区）、`MapView`（v1 坐标清单 + 腾讯地图跳转 + 待接入说明卡）、`MeView`（资料/统计/外观/关于/退出）。
  - **登录注册**：`AuthShell`（两栏）→ `AuthPanel`（同一背景舞台上的居中玻璃面板）；表单语义保持不变（原生提交 + name/autocomplete + 整页跳转）。
  - **背景系统**：`utils/background.ts`（预设/URL 校验转义/本地压缩 ≤1.2MB）+ `stores/appearance.ts`（localStorage 持久化、CSS 变量注入、光斑开关）。
  - **既有页面**：概览/详情玻璃化（卡片、时间轴、FAB 上移 96px 避让底栏、去掉页内 AppBar）。
- 验证结果：
  - type-check / lint（**两道令牌守卫**：硬编码色值 + 引用未定义令牌）/ build 全绿（40 个文件）；
  - 令牌级对比度 **11/11 通过**；**复合对比度（纯黑背景图 + 底线遮罩）4/4 通过**；
  - 模糊预算：`backdrop-filter` 仅存在于样式层（base/element），组件未自行添加；`glass-float` 仅顶栏与底栏使用；
  - 残留断言：旧令牌、`AuthShell`、`--wy-draw-length` 全部 0 处。
- 偏差与经验：
  1. **品牌色**按用户决策改为翡翠宝石系：深翡翠 `#047857`（白字 5.48:1）+ 亮翡翠/青玉 + 宝石家族渐变板（翡翠/青玉/蓝宝石/琥珀/橄榄石/紫水晶）。
  2. **复合对比度审计抓到 6 处最坏情况不达标**（纯黑背景 + 弱遮罩下最小字号文字）→ 联合求解后上调：`ink-3 → #476257`、scrim `0.62/0.42`、玻璃 `float 0.75 / panel 0.82 / strong 0.90`；全部达标（float·ink-3 = 4.73 为最紧）。
  3. **新守卫立即抓到一类真实缺陷**：`var(--wy-*)` 引用必须已在 tokens.css 定义——首跑即发现 `--wy-draw-length`（本地动画参数误用设计令牌前缀），已改名为 `--route-draw-length`。
  4. 落地页 SVG 不使用字面色值（`check-tokens` 不允许）：路径用描边色令牌，避免 `var()` 在 SVG 渐变属性中不解析的问题。
  5. 外壳组件统一在 `App.vue` 渲染（按 `route.meta.auth`），避免每个页面重复挂载；详情页的返回按钮由顶栏承担。
- 遗留（阶段 2）：腾讯地图 SDK 真接入（备案 + Key）、详情页深度打磨（拖拽排序/时间轴动效）、深色模式、日历周视图、后端聚合端点（消除日历/地图的 N+1 请求）。

## 12. 迭代追加（2026-09-29）：翡翠校准 · 主题色自定义 · 导航滑动指示器

**新增需求**：① 翡翠色要像参考图那样「透亮阳绿」；② 按钮/胶囊等主题色用户可自定义；③ 底部导航切换用「玻璃在胶囊上滑动」的流畅动效（并咨询线性 vs 非线性）。

**决策与实现**
1. **翡翠校准**：基准色改为 `#22c55e`（纯正阳绿，替换偏青的 `#10b981`）。派生结果（全部达标）：表面 `#41cd75`、高光 `#76db9b`、深色 `#157a3a`（白字 5.41:1）、弱底 `#dcf6e5`、宝石面墨色 `#052a1b`（7.55~9.15:1）。
2. **主题色自定义**：新增 `utils/theme.ts`（派生算法）+ 外观设置中的「主题色」区（8 套预设 + 任意自定义色 + 恢复默认）。
   - `--wy-accent-base` 为唯一基色；派生值由运行时注入（`--wy-jade/-jade-bright/-primary/-primary-strong/-primary-weak/-on-jade`）；默认保持 tokens.css 中已审计的静态值。
   - 算法内含两步保障：**墨色分支选择**（深墨/白墨取更优）与**迭代调整**（表面与深色逐步加深/提亮直到所有对比度 ≥4.5:1），因此任意用户配色都不会破坏可读性。
   - 已用 Node `--experimental-strip-types` 对拍 TS 与 Python 审计脚本（4 组基色输出完全一致）。
3. **语义分层**：正文/链接/边框用 `--wy-primary`（深色，白底可读）；按钮/胶囊/徽章/头像/FAB 用 `--wy-jade-surface` + `--wy-on-jade`（亮宝石面 + 深墨字）——这是「亮翡翠上必须用深色字」的落地方式；`TagChip` 由 `filled` 简化为 `tone="gem"`。
4. **导航滑动指示器**：底部胶囊内放置绝对定位的玻璃指示器，通过 `translateX + width` 实现跨项滑动；缓动取 **非线性弹簧** `cubic-bezier(0.34,1.56,0.64,1)`、420ms（线性会显得机械、无重量感）；首帧免动画直接落位、窗口 resize 重新测量、`prefers-reduced-motion` 下由全局规则关闭过渡。
5. **桌面端常驻左侧栏**（按用户要求，替代桌面端"只留抽屉"的方案）：新增 `DesktopSidebar.vue`（玻璃面板：品牌 + 四入口 + 外观设置，`position: sticky` 全高），与移动端抽屉共用 `SideNavContent.vue`（避免两套导航代码漂移）；`App.vue` 桌面下改为 flex 外壳（侧栏 + 主列），顶栏在桌面隐藏品牌与 ☰（避免重复），右上角用户信息不变。
   - 模糊层预算复核：桌面常驻模糊层 = 顶栏 + 侧栏（2 层），弹窗/浮层为瞬态，仍在 ≤4 预算内。
6. **修复（用户上报）**：移动端滑动指示器"定位框"消失——根因是函数式 `ref` 在 `router-link`（组件）上拿到的是**组件实例**而非 DOM 元素，`offsetLeft/offsetWidth` 为 `undefined` → 宽度 0；新增 `utils/dom.ts#resolveElement`（元素直传 / 组件取 `$el` / 异常返回 null），并加三层稳健性：量不到时**降级为激活项自带宝石背景**（激活态永不丢失）、120ms 二次校正、`orientationchange` + `ResizeObserver` 重测；`resolveElement` 单元检查 6/6 通过。
7. **修复（用户上报）**：桌面侧栏"与背景割裂、纯白"→ 迭代二："背景光球在侧栏/顶栏边界处截断"。
   根因：**霜化程度不一致**——主区域空隙全透明（光球原样透出），悬浮层罩了约 86% 白 → 同一个光球在边界两侧一亮一灭，读作"被截断"。
   修复：悬浮层不透明度从 0.80~0.86 **降到 0.38~0.44**（通透染色玻璃），使其与主区域的透明差距大幅缩小；同时**悬浮层文字全部改用最深墨色 `--wy-ink-1`**——这是能在低透明度下保住可读性的关键（求解：alpha 0.38~0.44 时最坏情况对比度 **5.9~6.6:1**、最亮 14:1+；而 ink-2 仅 2.6~3.4，不达标）；侧栏阴影改为 `8px/24px/0.06` 的极柔投影并去掉右侧高光硬线，避免在边界切出断裂感。
   验证：悬浮层 ink-1 最坏 5.9~6.6 / 最亮 14+；type-check / lint / build 全绿。
8. **顶栏透明化（用户要求"与主区域完全融合"）**：顶部状态**完全透明**（无背景、无边框、无阴影，仅品牌/按钮悬浮于背景之上），滚动超过 8px 后**渐显磨砂玻璃**（`appbar-scrolled` 状态）。
   - 为什么必须有滚动态：顶栏是 `sticky`，内容会从下方穿过——若始终全透明，滚动时文字会与内容重叠、可读性崩溃；"顶部透明 + 滚动磨砂"是同类产品（如 iOS 导航栏）的标准解法。
   - 对比度依据：页面顶部恰是遮罩最强处（白 0.62），最坏情况（纯黑壁纸）下 `ink-1` 对比度 **5.0:1**，透明顶栏安全。
   - 实现：`scrollY > 8` 切换状态；`passive` 监听 + `requestAnimationFrame` 节流；背景/边框/阴影 180ms 过渡，磨砂随状态切换。
   - 验证：type-check / lint / build 全绿。
9. **极光调淡 + 液态玻璃（用户要求）**：
   - 极光光斑 alpha 各降约 1/3（`0.62/0.52/0.44 → 0.42/0.34/0.26`），模糊 48→56px、光斑整体不透明度 0.92→0.78。
   - 玻璃升级为**液态玻璃 + 毛玻璃组合**：新增 `--wy-sheen`（镜面高光渐变，左上亮→中段极淡→右下回光）、`--wy-sheen-soft`（内容卡轻量版）、`--wy-lens-shadow`（四边内反光，制造"厚度"）并把饱和提到 180%；悬浮层与内容卡按不同强度组合这三种效果。
   - 顶栏"透明 → 磨砂"过渡改为**蒙层透明度淡入**（新增 `appbar-veil` 元素 + 220ms opacity 过渡）——渐变背景本身无法平滑插值，直接切换会硬切。
   - 复核（sheen 最弱处叠加 + 纯黑壁纸最坏情况）：悬浮层 ink-1 **6.27**、内容卡 ink-2 **5.65**、ink-3 **5.28**，全部达标（sheen 只补光，安全性不降反升）。
   - 验证：type-check / lint（43 个令牌引用全部有定义）/ build 全绿。
10. **圆润化 + 淡雅翡翠卡片 + 发光胶囊（用户要求）**：圆角整体加大（`--wy-r-sm/md/lg = 14/22/32`）；概览卡片移除顶部目的地色条（"贴标签"式配色与液态玻璃语言冲突），改为**整卡淡雅翡翠玻璃**（主题色染 8% + 白 86% + 轻量 sheen），目的地色板降级为 8px 小圆点保留辨识度；侧栏激活胶囊与底栏指示器由纯绿实心改为**透明淡绿光玻璃**（主题色染 16~18% + 白 28~30% + 描边光 + 外发光 + 轻毛玻璃），文字统一 `ink-1`。复核：翡翠卡片 ink-2 **5.65** / ink-3 **5.27**；侧栏胶囊 **7.86**；底栏胶囊 **7.94**，全部达标。
11. **详情页统一（用户指出"点进去之后还没改"）**：上一轮只改了列表卡片，详情页仍为旧配方。
    - 修复：`.glass-panel` / `.glass-panel-strong` / `.wy-card` **全站内容卡加入主题色轻染**（5% / 4%）→ 详情页 hero、日程卡、待定地点区自动变为淡雅翡翠玻璃；移除 hero 顶部渐变条（与概览卡同款问题）；`day-badge` 与两个 FAB 由实心翡翠改为**透明淡绿光玻璃**（与侧栏/底栏激活胶囊同款）。
