# ADR-20260929：视觉语言转向「出发感」——从纸感手账切换到清新旅行风

- 状态：已完成（Phase 5，2026-09-29；视觉验收待用户目视确认）
- 日期：2026-09-29
- 触发：用户反馈「当前 UI 更像笔记软件而不是旅行软件；纸面风格在旅途中不可取；旅行应清新、自由不被束缚、灵动、充满活力」
- 范围：设计令牌（色彩/字体/圆角/阴影/动效）重写 + 10 个组件/页面的视觉适配 + 手账味文案替换
- 不包含：布局结构大改（信息架构保持不变）、新功能、深色模式、图片/插画资源引入

---

## 1. 复盘：纸感为什么读作"笔记本"

| # | 元素 | 现状证据 | 心理联想 |
|---|---|---|---|
| 1 | 楷体/衬线标题 | `--wy-font-display` 用于 AppBar/弹窗标题/消息框（6 处） | 书刊、手写 |
| 2 | 宣纸米黄 + 噪点 | `--wy-paper-bg: #F7F3EC`、`base.css` feTurbulence 纸纹层 | 纸张 |
| 3 | 朱砂印章色 | `--wy-cinnabar: #B5432E` 作主色 + `SealTag` 旋转印章 | 信笺、图章 |
| 4 | 印刷式装饰 | 虚线分隔/虚线导轨/票根撕线/微旋转（SealTag -1.5°、卡片 -0.4°） | 手账贴纸 |
| 5 | 文案 | 「把旅途，写成一纸手账」等 | 笔记本 |

结论：**"旅行"与"手账"并不互斥，但本次要表达的是"户外/在路上"的活力，而不是"伏案记录"的静气**。用户的判断成立，属需求侧的类型选择，不是执行缺陷。

## 2. 新设计语言：出发感（Departure）

**核心隐喻**：清透的天空 + 流动的路线。装饰母题从"纸/印"换成"轨迹/光斑"。

| 目标（用户原话） | 设计手段 | 不变量 |
|---|---|---|
| 清新 | 冰蓝白底 + 纯白卡片；去纹理、去米黄 | 正文对比度 ≥ 4.5:1 |
| 自由不被束缚 | **去边框化**：以留白+阴影分层替代 1px 线框；圆角 12/16/24 | focus-visible 轮廓必须保留 |
| 灵动 | 弹簧缓动 hover（`cubic-bezier(0.34,1.56,0.64,1)`）、列表错峰淡入、FAB 轻呼吸 | 仅动 transform/opacity；≤240ms；prefers-reduced-motion 全关 |
| 活力 | 高饱和主色 + 珊瑚橙强调 + 青碧辅助；**数字发光**（天数/倒计时/地点数 大字+色块） | 渐变仅用于"信息头"，面积 ≤15%，禁用大面积渐变 |

## 3. 配色三方向（待用户选定）

| 令牌 | A 晴空·海蓝（推荐） | B 日出·活力 | C 青野·自然 |
|---|---|---|---|
| 背景 bg | `#F4F9FF` 冰蓝白 | `#FFF8F4` 暖米白 | `#F3FBF7` 薄荷白 |
| 表面 surface | `#FFFFFF` | `#FFFFFF` | `#FFFFFF` |
| 主色 primary | `#0E9BF0` 晴空蓝 | `#FF6B4A` 日出橙 | `#10B981` 青野绿 |
| 强调 accent | `#FF7A59` 日落珊瑚 | `#FFB020` 朝阳金 | `#0EA5E9` 天空蓝 |
| 辅助 teal | `#14B8A6` 青碧 | `#12A594` 松石 | `#F5A623` 暖阳 |
| 深色文字 | `#10303F` 深蓝墨 | `#2B2118` 暖褐墨 | `#0F2E24` 深松墨 |
| 次级文字 | `#4A5C66` | `#6B5B4E` | `#4A635C` |
| 弱文字 | `#8AA0AB` | `#A2938A` | `#8BA69E` |
| 分隔/底色 | `#E3EDF5` / `#EAF3FB` | `#F3E7DF` / `#FBF0E9` | `#DDEFE7` / `#E8F6F0` |

推荐 A：与"天空/飞行/在路上"的直觉最贴合，且冷色系与未来地图/照片的暖色元素搭配空间大；B 更热烈但大面积使用易显廉价；C 偏户外/自然，弱化"城市旅行"。

## 4. 令牌映射（旧 → 新，A 方向示例）

| 旧（手账） | 新（出发感） | 处理 |
|---|---|---|
| `--wy-paper-bg #F7F3EC` | `--wy-bg #F4F9FF` | 重命名 + 换色 |
| `--wy-paper-card #FFFDF8` | `--wy-surface #FFFFFF` | 重命名 + 换色 |
| `--wy-cinnabar` 等 6 个点缀色 | `--wy-primary/--wy-accent/--wy-teal` + weak 底色 | 收敛为 3 主色体系 |
| `--wy-font-display`（楷体栈） | **删除**，统一系统无衬线；标题用 `font-weight:650` + 紧字距 | 手卷气主因 |
| 纸纹噪点层（base.css） | **删除** | — |
| 虚线/旋转装饰 | 实线浅色 + 渐变节点；移除全部 rotate | — |
| 阴影（暖褐 rgba(90,70,40,·)） | 冷调阴影 rgba(16,64,96,·)，两档不变 | 层次改为"阴影承担" |
| 动效 `--wy-ease` | 增加 `--wy-spring: cubic-bezier(0.34,1.56,0.64,1)` 用于交互反馈 | — |

## 6. 风险与反例

| 风险 | 对策 |
|---|---|
| 浅蓝底 + 白卡对比不足，弱视用户辨识困难 | 卡片阴影加强一档；文本对比度按 WCAG AA 抽查；保留 focus-visible |
| 渐变滥用导致"廉价电商感" | 渐变仅用于信息头（卡片顶条/日节点/FAB/logo），面积 ≤15%，且同屏 ≤3 处 |
| 动效过多导致分心/卡顿 | 仅 transform/opacity；≤240ms；`prefers-reduced-motion` 全关；列表错峰 ≤30ms/项 |
| 换色后 EP 状态色失衡（danger/warning 与蓝主色冲突） | 重新配平：danger `#F04438`、warning `#F79009`、success `#12B76A` |
| 运输/截图场景（以后做分享图）字体缺失 | 全系统无衬线栈，零字体下载策略不变 |

## 9. 最终结果（Phase 5）

- 实际变更：
  - `tokens.css` 全量重写：青野·自然三分色（青野绿/天空蓝/暖阳）+ 冷调阴影 + 圆角放大（10/16/24）+ 弹簧缓动 `--wy-spring`；新增品牌渐变两档与六组目的地渐变板。
  - `base.css`：删除纸纹噪点层；标题/卡片全无衬线（`.wy-display` 改为高字重无衬线）；卡片去边框化（阴影承担层次）；新增 `wy-rise` 错峰入场动画（reduced-motion 全局关闭）。
  - `element.css`：Element Plus 换绿色系主色 + 状态色配平（danger `#D92D20`、success `#12B76A`、warning `#F79009`）+ 圆角/overlay/tag 胶囊化 + 弹窗标题去楷体。
  - 组件层：`SealTag` → `TagChip`（胶囊三态，删除旧文件并更新全部引用）；`TripCard` 票根 → 渐变头清爽卡（统计带柔底、倒计时暖色胶囊、弹簧抬升）；`AppBar`/`AuthShell` 印章 → 深渐变品牌块；`EmptyState` 插画加柔渐变底；`TripsView`/`TripDetailView` 时间轴实线化 + 渐变日徽章 + FAB 渐变化。
  - 文案与元信息：登录页「去哪里，都从这里出发」、注册页「下一段旅途，从这里开始」、`index.html` 描述与 theme-color、favicon 渐变重制。
- 验证结果：
  - type-check / lint（含 check-tokens 守卫）/ build 全绿；
  - 残留断言：旧令牌（paper/cinnabar/indigo/moss/gold/plum/wood/font-display）**0 处**；`dashed`/`rotate(`/`feTurbulence`/楷体 **0 处**（仅注释提及）；
  - **WCAG 对比度 15/15 通过**（脚本量化，阈值 4.5:1）。
- 偏差与经验（重要）：
  1. 原定主色 `#10B981` 经审计白字仅 **2.54:1**（不合格）→ 拆分为 **`--wy-primary`（#067A55，交互/填充，5.35:1）** 与 **`--wy-primary-bright`（#10B981，仅装饰渐变）**；并新增 `--wy-grad-brand-deep` 专用于承载白色文字/图标的元素（FAB、日徽章、品牌块）。
  2. 弱字 `#8BA69E` 仅 2.61:1 → 调深至 **`#567268`**（白底 5.25 / 页面底 4.99 / 柔底 4.71）；天空蓝与暖阳文字同步新增 `-strong` 变体（#0369A1 / #92400E）。
  3. 动效纪律：全部仅动 transform/opacity，时长 ≤340ms，`prefers-reduced-motion` 下由既有全局规则关闭。
  4. 浏览器工具在本环境不可用，视觉验收依赖用户目视；对比度以脚本量化替代部分目视检查。
- 遗留：深色模式未做；目的地渐变板为纯色渐变，未来接入照片后可与其叠加；EP 全量引入的包体优化仍列 backlog。
